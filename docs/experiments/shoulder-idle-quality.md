# 어깨 외곽선·연결부 대기 동작

작성일: 2026-09-23. `local-idle-v1`의 내부 무늬 변형을 외곽선 움직임으로 확장한 기사 전용 절차적 후보다. AI 생성이나 자동 리깅 방식은 아니다.

## 구현

- `src/lib/image/shoulder-motion.ts`: 원본 RGBA를 역방향 최근접 샘플링한다. 불투명 픽셀뿐 아니라 투명 픽셀도 옮겨 외곽선이 최대 1px 움직인다. 원본 색을 재사용하고 새 색/반투명 픽셀을 만들지 않는다.
- `fixtures/poses/knight-shoulder-idle.json`: 편집 영역 (24,24,12,8), 가로 기준 x=29, 프레임별 행 이동을 명시했다. 영역 밖은 원본 그대로다. 선택한 기준 이미지 해시가 달라지면 실행을 거절한다.
- 목 바로 아래 연결 행 y=23, 어깨 아래 연결 행 y=31 및 팔 시작 행 y=32는 고정한다. 움직임이 고정 연결 행에 닿기 전에 줄어들도록 행별 이동을 지정했다.
- 오른쪽 여유 열이 부족하면 조용히 자르지 않고 실패한다. 크기/알파/중복 행/이동 범위/연결 행 수정도 검증한다.
- 기존 출력 도구에 설정 파일 인수를 추가했다. 이전 마스크와 출력 방식도 그대로 지원한다.

## 결과

폴더: `data/experiments/shoulder-idle-v1/`. PNG 4장, 256×64 시트, JSON, GIF, 재생 HTML, 편집 마스크, 전체/확대 비교 이미지를 저장했다. 타임라인은 350/200/350/200ms로 총 1.1초, 고유 자세는 3개다.

| 프레임 | 원본 대비 변경 픽셀 | 외곽선 알파 변경 | 보호 영역 변경 |
|---|---:|---:|---:|
| 휴지 | 0 | 0 | 0 |
| 들숨 | 7 | 2 | 0 |
| 유지 | 44 | 7 | 0 |
| 날숨 | 7 | 2 | 0 |

프레임 전환 변경량은 7→41→41→7px다. 얼굴·팔·검·하체·발 및 지정 연결 행은 원본과 동일하다. 중간/최대 자세에서 외곽선 변화가 실제 발생하는지 출력 시 검사한다.

4방향 연결 기준으로 캐릭터 연결 성분 1개, 닫힌 배경 영역 1개를 모든 프레임에서 유지한다. 원래 몸과 검 사이의 배경을 유지했으며 신규 분리나 닫힌 틈이 생기지 않았다. 이 검사만으로 관절의 자연스러움까지 보장하지는 않는다.

확대 검수에서 이전 후보보다 어깨 갑옷의 부피 변화가 드러나고 목/팔 접합은 유지되는 것을 확인했다. 원래 픽셀 스타일에서 1px 단계로 움직이므로 최대 자세에서 변화가 다소 뚜렷하다. 머리와 팔을 고정한 작은 대기 동작 후보로 유지하며 전신 호흡·달리기·공격 품질이나 P0 전체 통과로 판정하지 않는다.

## 검증

- 테스트 20개 통과. 영역 밖 보호, 외곽선 이동, 복원, 잘림/잘못된 입력 거절 포함.
- 기존 `local-idle-v1` 설정을 임시 폴더에서 재실행하고 네 PNG가 기존 파일과 바이트 단위로 동일함을 확인.
- 시트 rect를 다시 잘라 개별 프레임과 픽셀 일치 확인. GIF 프레임 수/시간/무한 반복 확인.
- 브라우저 이미지 로드·재생·일시정지·한 프레임 이동·끝→처음 순환·재개 확인.
- 프로덕션 빌드 통과. lint 오류 0개, 기존 img 경고 2개.

## 후속 범위

한 기사에 맞춘 수동 마스크라는 한계가 남아 있다. 다음에는 다른 체형의 기준 이미지에도 보호 부위/움직일 부위를 지정해 같은 검증을 적용하고, 마스크 지정 비용과 후보 채택 가능성을 평가한다. 현재 마스크를 다른 캐릭터에 그대로 재사용하거나 이 실험만으로 범용 생성 품질을 주장하지 않는다.
