# 고정 부위 보존형 대기 동작

작성일: 2026-09-23. 이전 전신 img2img 실험의 외형 흔들림을 줄이기 위한 P0 후속 작업.

## 구현과 범위

`src/lib/image/local-motion.ts`에 64×64 원본의 지정 영역만 최근접 행 재표본화하는 처리를 추가했다. 블렌딩이나 팔레트 재추출 없이 원본 색을 재사용한다. 영역 외 픽셀과 실루엣/투명도를 유지하며, 영역 중복·크기 오류·1px를 넘는 변형은 거절한다. 각 프레임을 같은 원본에서 만들어 누적 변형을 피한다.

`fixtures/poses/knight-local-idle.json`은 이번 기사 전용 수동 마스크와 타이밍이다. 어깨 (27,25,7,7), 가슴 (25,32,4,4)만 수정하고 나머지는 고정한다. 기준 PNG의 SHA-256을 확인하므로 다른 캐릭터에 같은 좌표를 잘못 적용하지 않는다. 자동 신체 분할이나 범용 캐릭터 리깅은 구현하지 않았다.

이 결과는 **절차적 부분 변형 후보**다. AI로 새로운 자세를 생성한 결과가 아니며, 이번 실행에서는 모델 호출·설치를 하지 않았다. 가이드가 아니라 실제 재생/출력 가능한 후보 프레임을 만들었지만, 자연스러운 전신 호흡이나 P0 전체 합격으로 판정하지 않는다.

## 출력

경로: `data/experiments/local-idle-v1/`

- `idle-0.png`~`idle-3.png`: 네 타임라인 프레임, 각각 64×64 RGBA.
- `idle-sheet.png`: 256×64 가로 스프라이트 시트.
- `idle.json`: 영역, 기준 해시, 프레임 rect, 시간, 방향, 반복, 기준점 (32,56), 변경 픽셀 수.
- `preview.gif`: 384px 최근접 확대 재생 미리보기.
- `review.html`: 원본/후보 비교, 재생·일시정지·한 프레임 이동. PNG를 내장하여 파일 단독으로 열 수 있다.
- `editable-mask.png`, `mask-preview.png`: 편집 영역과 분홍색 오버레이.
- `comparison.png`: 네 프레임 정적 비교.

타이밍은 350 → 200 → 350 → 200ms, 총 1.1초다. 들숨/날숨에 같은 중간 자세를 사용하여 **고유 자세는 3개**다. 네 개의 서로 다른 AI 생성 자세로 표시하지 않는다. PNG/JSON이 원본 산출물이며 GIF는 미리보기다.

## 검증 결과

| 프레임 | 원본 대비 변경 픽셀 | 보호 영역 변경 | 알파 변경 |
|---|---:|---:|---:|
| 0 휴지 | 0 | 0 | 0 |
| 1 들숨 | 32 | 0 | 0 |
| 2 유지 | 34 | 0 | 0 |
| 3 날숨 | 32 | 0 | 0 |

- 모든 프레임의 색이 원본 색 집합 안에 있다. 얼굴·팔·검·하체와 발은 원본 픽셀을 유지한다.
- 첫 프레임은 선정 기준 PNG와 해시까지 동일하다.
- 시트의 각 rect를 다시 잘라 개별 프레임과 픽셀이 같은지 검사했다.
- 루프 전환 변경량은 32 → 2 → 2 → 32px. 끝→처음에서 보호 영역 변화는 없다. 이 수치만으로 자연스러움을 판정하지 않는다.
- GIF의 프레임 수 4, 반복 0(무한), 시간 [350,200,350,200]을 디코딩하여 확인했다.
- 테스트 18개 통과, 프로덕션 빌드 통과, lint 오류 0(기존 img 경고 2개).
- 브라우저에서 이미지 64×64 로드 및 재생·일시정지·한 프레임 이동·재개 동작 확인. 마스크/비교 이미지와 재생 화면을 시각 검수했다.

## 판정과 다음 단계

후속 작업: [어깨 외곽선·연결부 대기 동작](shoulder-idle-quality.md)에서 외곽선을 움직이는 별도 후보를 구현하고 기존 결과와 비교했다.

고정 부위 보존이라는 기술 목표는 달성했다. 시각적으로 어깨 갑옷 내부에 작은 변화가 있지만 외곽선과 머리가 고정되어 움직임이 제한적이다. 자연스러운 호흡 클립으로 최종 채택하지 않고, **외형 보존 처리를 확인하는 기준 후보**로 보관한다.

다음에는 보호 영역 검사를 그대로 유지하면서 어깨 외곽선까지 움직일 수 있는 레이어/마스크와 연결부 처리를 비교해야 한다. 수정 영역 밖 픽셀을 원본에서 복원하는 규칙은 부분 생성 방식에도 재사용할 수 있다. 달리기·공격이나 다른 캐릭터는 별도 검증이 필요하다.
