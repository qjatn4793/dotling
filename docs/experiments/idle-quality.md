# 대기 자세 간 외형 일관성 실험

작성일: 2026-09-23. P0 후속 검증. 이전에 선정한 `knight-side-v1` 한 캐릭터로 범위를 제한한다.

## 실험 구성

- 외형 초기화: 선정 캐릭터의 768×768 투명 cutout을 흰 배경에 합성한 이미지. 두 조건 모두 동일하다.
- 자세 제어: 원본 상체를 12 source px 올리고 허리에서 이동량을 0으로 줄인 가이드. 발과 다리는 고정한다. 가이드는 기하학적 변형이며 생성된 애니메이션으로 세지 않는다.
- Canny 입력과 VAEEncode 입력을 별도 LoadImage로 분리한다.
- 기존 SDXL/LoRA/seed/20 steps/CFG7 설정 유지. denoise 0.25, 0.4 두 조건 비교.
- 새로운 모델·패키지는 설치하지 않는다.

## 프레임 공통 처리

`src/lib/image/frame.ts`는 기준 이미지의 좌표 변환을 모든 프레임에 재사용한다. 기준 몸체의 경계 밖으로 움직인 머리·검도 64px 캔버스 안이면 유지하며, 프레임마다 bounding box를 다시 맞추지 않는다. 소스 크기가 바뀌거나 불투명 픽셀이 출력 캔버스를 벗어나면 중단한다.

고정 팔레트는 기존 기사 전용 16색을 사용한다. 배경 제거 후 자세 마스크의 기본 제거 한도 5%를 유지한다. 제거 픽셀이 많으면 시각 검수 없이 한도를 높이지 않는다.

기준 프레임도 같은 샘플러로 다시 출력한다. 이전 단일 이미지 정규화와 샘플링 경계에서 차이가 있을 수 있으므로 이번 비교의 기준은 `baseline.64.png`이다. 기준 캐릭터 선정 파일은 덮어쓰지 않는다.

## 재현

기존 모델이 설치된 ComfyUI를 `127.0.0.1:8188`에 실행한 후:

```sh
npm test
node scripts/idle-quality.mjs
node scripts/review-idle.mjs
```

실행 폴더: `data/experiments/idle-quality-v1`. 완료된 작업은 해시를 검사해 재사용한다.

- `appearance.png`, `pose.png`: 분리된 입력.
- `*.workflow.json`, `*.job.json`: 요청 설정·실행 기록.
- `*.before-mask.png`, `*.cutout.png`, `*.64.png`: 후처리 전후.
- `metrics.json`: 공통 변환, 팔레트, 변화 픽셀, 하체 변화, 최하단 픽셀 좌표.
- `comparison.png`, `review.html`: 정적 비교 및 두 자세 교대 검수 화면.

수치만으로 외형 유지나 자연스러운 움직임을 판정하지 않는다. 발바닥의 최하단이 같아도 발 모양이 변할 수 있다. HTML은 두 자세 비교용이며 4프레임 대기 애니메이션으로 표시하지 않는다.

마스크 한도를 넘은 결과는 강제로 자르지 않는다. 검수 도구는 `rejected_unmasked_diagnostic`으로 기록하고 배경 잔여물이 있는 진단 이미지를 비교 화면에 표시한다. 이는 채택 가능한 투명 스프라이트가 아니다. `*.mask-review.png`의 빨간 부분은 제거 예정 픽셀이며, 실제 제거를 적용했다는 뜻이 아니다.

## 실제 결과와 판정

**두 조건 모두 미채택. 4프레임 대기 루프 확장 보류.**

| 조건 | 작업 경과 시간 | 기준 대비 변경 픽셀 | 하체 변경 픽셀(y≥44) | 최하단 y | 마스크 예정 제거율 |
|---|---:|---:|---:|---:|---:|
| denoise 0.25 | 약 211초 | 269 / 607 (44.3%) | 124 | 55 | 5.54% |
| denoise 0.40 | 약 118초 | 291 / 605 (48.1%) | 128 | 55 | 5.54% |

첫 작업은 모델 로딩을 포함하므로 생성 강도의 속도 차이로 해석하지 않는다. 변경 비율의 분모는 두 프레임 불투명 영역의 합집합이며, 닫힌 배경 잔여물도 포함한다. 정체성 정확도 점수가 아니다.

시각 검수에서 오른쪽 측면과 전체 장비 구성은 유지했으나, 요구한 상체 상승은 충분히 나타나지 않았다. 부츠·팔·갑옷의 명암 무늬가 바뀌어 두 자세 교대 시 깜빡임이 예상된다. 발바닥 최하단이 같다는 사실만으로 발 모양 유지나 동작 품질 통과로 판정하지 않았다.

마스크 제거 예정 영역에는 몸과 검 사이의 닫힌 배경뿐 아니라 코와 턱 일부도 포함했다. 한도를 올리거나 강제로 잘라 자세가 맞는 것처럼 만들지 않았다. 비교 이미지는 마스크 적용을 거절한 진단 결과이며 원본 기준 캐릭터를 대체하지 않는다.

## 다음 구현 우선순위

후속 진행: [고정 부위 보존형 대기 동작](local-idle-quality.md)에서 아래 1~2의 절차적 변형을 구현하고 네 프레임 후보를 출력했다. 외형 보존 기술 검증과 자연스러운 동작의 최종 채택은 구분한다.

1. 대기 동작에서 고정할 부위(발·하체·무기)와 움직일 부위(가슴·어깨)를 명시한 마스크를 만든다.
2. 고정 부위의 원본 픽셀을 보존하고 움직일 영역만 변형/부분 생성하는 실험을 추가한다. 단순 기하학적 가이드와 실제 생성 프레임을 구분한다.
3. 목표 움직임의 반영과 외형 유지가 동시에 확인된 후 4프레임 루프를 만든다.
4. 큰 자세 변화인 달리기·공격은 별도 참조 임베딩/학습 방식의 필요성을 평가한다. 이번 방식의 두 실패를 모든 방식의 실패로 일반화하지 않는다.

검증: 테스트 16개 통과, 프로덕션 빌드 통과, lint 오류 0개(기존 img 경고 2개). 실제 생성 2건과 입력 가이드·마스크 오버레이·64px 비교 이미지를 시각 검수했다.
